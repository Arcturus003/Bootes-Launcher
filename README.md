## 🌟 Why Bootes Launcher? | Neden Bootes Launcher?

Bootes Launcher is built for players who want a beautiful, seamless, and powerful Minecraft experience without the clutter. 
*Bootes Launcher, karmaşadan uzak, şık, pürüzsüz ve güçlü bir Minecraft deneyimi isteyen oyuncular için tasarlandı.*

### ✨ Core Features
- 🔒 **Premium Only:** Secure Microsoft OAuth2 authentication.
- 📦 **Modrinth Integrated:** Search, browse, and install modpacks directly from Modrinth with one click.
- 🖥️ **1-Click Dedicated Server:** The only launcher that downloads and sets up a dedicated server (Vanilla, Forge, Fabric) right from the UI so you can play with friends instantly!
- 🔄 **Cross-Launcher Sync:** Automatically detects and migrates your existing profiles from third-party launchers (like TLauncher).
- 📂 **Local Modpacks:** Easily drag and drop .zip or .rar modpacks to install them locally.
- 🎨 **Cosmic UI:** A modern, customizable space-themed interface built on PySide6.

## 📥 Installation (Kurulum)

1. Go to the [Releases](https://github.com/Arcturus003/Bootes-Launcher/releases/latest) page.
2. Download the latest BootesLauncher_Setup_vX.X.X.exe file.
3. Run the installer and you are ready to explore the universe!

*(Note: Requires a Premium Minecraft account / Microsoft Login).*
