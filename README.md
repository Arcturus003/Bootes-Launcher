# Vega Launcher

A modern, custom Minecraft Launcher with built-in Modrinth integration, premium authentication, and local modpack support.

## Features
- **Modrinth Integration**: Directly browse and install mods, modpacks, and shaders from Modrinth.
- **Local Import**: Install local .zip and .rar modpacks easily.
- **Multi-Instance**: Separate folders for each profile, allowing different mod versions and saves without conflict.
- **Premium Security**: Requires a genuine Microsoft/Minecraft Premium account.
- **Auto-Updates**: Built-in updater keeps the launcher fresh.

## Installation
Currently, Vega Launcher is distributed as a standalone Windows installer.
1. Download the latest VegaLauncher_Setup_vX.X.X.exe from the [Releases](../../releases) tab.
2. Run the installer and follow the instructions.
3. Sign in with your Microsoft account and start playing!

## Development
To build the launcher from source:
1. Clone the repository.
2. Install requirements using pip install -r requirements.txt.
3. Build the application using PyInstaller.
